# 🎨 Prompt

## Design a Complete Modern UI/UX for "HealthForecast AI"

**Prompt:**

> Design a complete, modern, premium-quality UI/UX prototype in **Figma** for an AI-powered healthcare platform named **HealthForecast AI: Hospital Readmission Prediction & Patient Risk Intelligence System**.
>
> **Important Instructions:**
>
> * Design **ONLY the frontend UI/UX**.
> * **Do NOT generate any backend logic, database schema, API integration, authentication implementation, or code.**
> * This task is strictly limited to creating a high-fidelity Figma design and interactive prototype.
> * Every screen should appear realistic, polished, responsive, and suitable for a production-level healthcare SaaS platform.
