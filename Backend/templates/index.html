🤖 About the AI Model

HealthForecast AI predicts hospital readmission risk for diabetic patients using a Stacking Classifier.

The pipeline consists of:

  • ✔ Data Cleaning
  • ✔ Label Encoding
  • ✔ StandardScaler
  • ✔ SMOTE for Class Balancing
  • ✔ Random Forest
  • ✔ XGBoost
  • ✔ CatBoost
  • ✔ Logistic Regression (Meta Learner)

The final prediction is generated after preprocessing the patient information and passing it through the trained ensemble model.
