# HealthForecast-AI
## Hospital Readmission Prediction & Patient Risk Intelligence System

## Overview

This project predicts whether a diabetic patient is likely to be readmitted to the hospital using Machine Learning.

The project includes:

- Data preprocessing
- Missing value handling
- Feature engineering
- Machine Learning model training
- Model evaluation
- Patient risk prediction
