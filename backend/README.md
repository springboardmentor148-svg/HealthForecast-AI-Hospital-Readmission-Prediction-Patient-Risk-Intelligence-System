## 🚀 1. Local Architecture Installation

Follow these steps to set up the local development environment:

```bash
# 1. Clone the project architecture repository and enter the directory
cd Diabetics-Backend

# 2. Build a sandboxed python virtual environment
python3 -m venv venv

# 3. Activate the virtual runtime matrix
# On macOS/Linux:
source venv/bin/activate
# On Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# 4. Install compiled library constraints from pip package manager
pip install -r requirements.txt
